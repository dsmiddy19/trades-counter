Prepare a safe rollback

Choose “Prepare restore” on a previous build above. No change will happen to your live dashboard.

Open GitHub rollback workflow
  1. On GitHub, click Run workflow and use the main branch
  2. Paste the full selected commit SHA into target_commit and run
  3. Open the resulting pull request, review what changed, and click Merge if it looks right

The rollback changes only index.html. Your GitHub API secret, economic calendar, market context, and scheduled updates stay intact. A rollback to a very old UI might not show the History link, but /trades-counter/history.html remains available.

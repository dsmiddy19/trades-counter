Each episode starts with the first qualifying threshold crossing and groups later same-direction crossings during the selected window, for the same market, threshold and filter setting. "Both ratios" means each ratio crossed at some point during that episode, not necessarily simultaneously. Only the first crossing's forward price and VWAP movement counts toward the episode outcome. These time-window groups reduce duplicate counts, but do not guarantee statistically independent samples. All executions always includes every filtered execution. Positive price and VWAP percentages mean movement in the aggression direction (BUY up, SELL down). Both ratios use the same rolling window and require ≥1,000 total units of the base asset on the dominant side before an event is logged. The filtered variant additionally requires ≥10 qualifying executions. The $1,000 filter is a provisional per-execution USD-notional cutoff, not 1,000 orders and not a verified TensorCharts setting. Only new, observed crossings are recorded (5m cooldown). Pending checkpoints survive page refreshes. A recorded price/VWAP sample within 10 seconds of the checkpoint provides the full measurement. If that sample is missing, Coinbase 1-minute candle data may recover an approximate price only; VWAP is explicitly unavailable and that estimate is excluded from full follow-through statistics. Research data is stored only in this browser, up to 120 events. No predictive accuracy is claimed.
